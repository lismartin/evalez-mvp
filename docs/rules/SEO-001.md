# SEO-001 - Intencion de indexacion y noindex

- Entrada: intencion explicita de indexacion y respuesta HTML exitosa con meta-robots/X-robots evaluable.
- Disparador: `noindex` efectivo contradice una intencion indexable.
- Clasificacion: `confirmed_problem`, gravedad `medium`, prioridad `later`, confianza `high`.
- Exclusiones: intencion desconocida es `review_note` con prioridad `review_required`; noindex intencional es informacion.
- Evidencia: ruta, directiva efectiva e intencion versionada del operador.
- Correccion: retirar el noindex contradictorio en la misma pagina.
- Huella: ruta de pagina normalizada.
