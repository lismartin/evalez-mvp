# TLS-001 - Validacion del certificado

- Entrada: conexion HTTPS con SNI correcto, almacen de confianza y hora UTC.
- Disparador: certificado caducado, aun no valido, nombre no coincidente o cadena no confiable.
- Clasificacion: `confirmed_problem`, gravedad `high`, prioridad `act_now`, confianza `high`.
- Exclusiones: DNS, timeout y conexion bloqueada son `blocked`; no se desactiva TLS.
- Evidencia: host, hora, vencimiento, inicio de validez, coincidencia de nombre y confianza de cadena.
- Correccion: certificado valido para el host, dentro de su periodo y con cadena confiable.
- Huella: causa `expired`, `not_yet_valid`, `name_mismatch` o `untrusted_chain`.
